# FrostByte 1.0.0 — Community

- Initial Community release, licensed under Apache-2.0.
- Official Blackfrost theme, bulk model management, and device detail dashboards.
- Opt-in LAN and WireGuard overlay discovery for devices on your own network.
- No app analytics and no automatic diagnostic reports. Manual feedback contains
  only what you review and choose to send.
- Six release files are authenticated by a GPG-signed SHA-256 checksum list.

[Download for Mac, Windows and Linux](https://blackfrostai.com/frostbyte#downloads) ·
[User guide](https://blackfrostai.com/frostbyte/guide)

Existing users: Settings → Updates → Check now. Optional daily checks are available;
you decide when to download and install. The Mac app is Developer ID signed but not
notarized by Apple, and Windows packages are not Authenticode signed. Keep
operating-system protections enabled.

The existing Hugging Face, BitTorrent, IPFS, grouped transfer, sharing and device
features carry forward. Publisher identity setup does not publish files; Frost-Net
and the combined AEON Raspberry Pi image are not included in this release.
